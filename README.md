# Rescate de Cosechas Agrícolas

## Descripción del proyecto

Sistema web que busca conectar a pequeños productores agrícolas con compradores interesados en adquirir cosechas que no han logrado comercializarse oportunamente, evitando que estos productos se pierdan.

## Objetivo general

Diseñar un sistema web que facilite la publicación y comercialización de cosechas agrícolas no comercializadas, conectando productores y compradores mediante una plataforma digital.

## Usuarios del sistema

- **Productor agrícola:** registra y publica sus cosechas disponibles.
- **Comprador:** consulta las cosechas y envía solicitudes de adquisición.
- **Administrador:** supervisa y modera las publicaciones.

## Funcionalidades principales

- Registro e inicio de sesión.
- Publicación de cosechas agrícolas.
- Edición y cierre de publicaciones.
- Consulta y búsqueda de productos.
- Filtrado de cosechas por ubicación.
- Envío y gestión de solicitudes.
- Consulta del estado de las solicitudes.
- Administración de publicaciones reportadas.

## Alcance

La plataforma permitirá publicar cosechas, consultar productos disponibles y gestionar solicitudes entre productores y compradores.

No incluirá pagos electrónicos, transporte, almacenamiento ni gestión logística.
